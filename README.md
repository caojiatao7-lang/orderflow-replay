# 盘口回放 · Orderflow Replay

把报单、撤单、成交放回当时的市场。浏览器本地解析的订单与五档行情复盘工作台。

## 功能

- 报单、撤单、最后成交事件与行情联动；不足1秒的事件按数据精度合并。
- 连续五张真实快照：五档买卖挂量、相邻快照成交量增量，不补造半秒快照。
- 多合约中间价叠加、拖选时间放大、共享指针与逐帧回放。
- 当前中间价排序；成交量、五档买卖挂单差联合筛选及前后命中跳转。
- 有完整持仓和费用资料时按先进先出估算逐次平仓净盈亏，含合约乘数和开平手续费分摊；不包含信息费、返还或做市奖励。

## 启动

Node.js 20+、Python 3；无需 npm install，无第三方前端依赖。

```sh
node scripts/generate-demo.mjs
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 http://127.0.0.1:8080/web/ 。选择“行情对比”查看五个虚构合约，也可手动导入文件。

```sh
npm test
npm run check:privacy
```


## 隐私

只有源码和虚构演示数据，不含真实行情、个人委托、费用文件、私有部署配置。没有复制旧仓库历史。导入文件在浏览器内解析，代码不主动上传交易文件；浏览器与第三方扩展仍由使用者管理。实盘数据放仓库外。忽略规则不能替代人工检查提交文件与历史。

格式和精度限制见 [数据说明](docs/DATA.md)。只用于历史观察，不是自动交易程序；五档变化无法单独识别成交、撤单、新挂单或队列位置。
