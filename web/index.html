导入行情或交易复盘记录

只看行情可直接多选不同合约的行情 CSV，无需委托文件。也可选择一个复盘包（.json / .json.gz），或同时导入委托与行情。计算扣费盈亏时，可同时选择成交统计 CSV。支持 UTF-8、GB18030，文件只在浏览器内解析。

支持的文件

① 当前“所有委托单”导出或标准委托模板；② 带中文／英文表头或原始 CTP 顺序的五档行情；③ 成交统计 CSV（实际手续费）；④ 完整复盘包或本页导出的窗口 JSON / JSON.GZ（单独导入）。

CSV 订单无日期时按上方日历补全；JSON 复盘包使用包内日历。只导入所选交易日的 CSV 行情。单文件最大 200 MB，每次最多 60 万快照。

手动导入文件不会上传；刷新后恢复内置数据。

从一笔订单，看到当时的市场

  1. 载入数据

    打开页面默认加载公式生成的虚构订单与五合约示例。点击“行情对比”可同时观察多合约；只导入行情 CSV 时自动进入对比模式。查看其他记录时，选择交易日并同时导入委托文件和相关合约行情文件；手动导入仅在浏览器内解析，刷新后恢复默认包。

  2. 选择订单与事件

    左侧可按合约、成交／撤单状态和订单编号筛选。选中后切换“报单、撤单、最后成交”，查看相应时间附近行情。

  3. 移动指针或播放

    点击折线图、拖动进度条，或按左右方向键逐张查看。空格键播放／暂停。下排同时显示当前指针附近五张连续快照。

  4. 区分时间精度

    秒级订单时间以整秒区间表示；同秒行情与订单的先后顺序无法确定。不要把参考时刻当成真实毫秒事件时间。

  5. 保存观察窗口

    “导出窗口”只保存当前行情窗口和关联订单，可再次导入，不会生成伪造的逐笔成交数据。实时交易日志需要先转换为支持的 CSV 格式。

此工具用于观察与复盘。行情是快照；不据此重建真实队列位置、主动成交方向或毫秒级撮合顺序。
