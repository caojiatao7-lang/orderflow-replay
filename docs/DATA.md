# 数据与计算口径

支持行情/委托 CSV 和 version=1 的 JSON / JSON.GZ 复盘包。UTF-8 优先，失败时尝试 GB18030。行情字段见 web/model.mjs 的 MARKET_FIELDS；委托字段映射见 normalizeOrder。不同软件导出格式可能需要适配。

示例结构见 examples/synthetic-replay.json。orders 为委托，markets[合约].snaps 为快照。t 是毫秒时间戳，bids/asks 各五组 [价格,数量]，v 是累计成交量，dv 是同交易日相邻快照差；首条或交易日切换未知。demo1～demo5 全为虚构标的。

以完整北京时间对齐，使用指针时刻或之前最近快照。重复时间戳取最后源行；不代表实际撮合顺序。启用筛选排除滞后超过2秒、文件结束之后的盘口。挂单差 = 五档买量总和 − 五档卖量总和；不是主动买卖量。快照间隔遵循原文件，不强制半秒。

原始订单只有秒精度时不能推断毫秒延迟。“最后成交”不是完整逐笔成交明细。净盈亏需要合约乘数、成交数量/均价、实际费用分组和可配对开仓；缺费用时显示未知。未平仓的开仓费用不计入已平仓净收益。

单文件限制200MB，总快照60万、订单20万；大文件还受浏览器内存限制。
